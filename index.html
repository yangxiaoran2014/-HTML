计算原理与公式

一维稳态导热：通过每一层材料的热流密度 q 相等，各段温降与其热阻成正比。

热阻：R = δ / λ   （δ 单位 m）
内表面对流：R₁ = 1 / h₁     外表面对流+辐射：R₂ = 1 / h₂
总热阻：R_total = R₁ + Σ(δᵢ / λᵢ) + R₂
热流密度：q = (T_热侧 − T∞) / R_total
逐段降温：T_冷面 = T_热面 − q · δᵢ / λᵢ
外表面温度：T_out = T∞ + q · R₂ = T∞ + q / h₂

圆筒壁（炉膛，按每米长度计算）：

每层热阻：R_L,i = ln(r_{i+1} / r_i) / (2π·λᵢ)
内/外表面对流：R₁ = 1/(2π·r₁·h₁)，R₂ = 1/(2π·r_N·h₂)
线热流：q_L = (T_热侧 − T∞) / (R₁ + ΣR_L,i + R₂)   [W/m]
外表面热流密度：q″ = q_L / (2π·r_N)   [W/m²]

外表面换热系数（自动模式）：

h₂ = h_conv + h_rad
h_conv = 1.42·(ΔT / H)^0.25  （竖壁空气自然对流，层流）
h_rad = ε·σ·(T_s⁴ − T∞⁴) / (T_s − T∞)，σ = 5.67×10⁻⁸

若只给内侧表面温度（不外给 h₁），则应取 R₁ = 0，直接由内表面温度开始逐层降温，结果与上式一致。

导热系数随温度变化时（λ = λ₀ + b·t），λ 依赖于尚未求出的温度，程序用迭代法求解：先假设各层温度，算出温度场后用 该层两端温度的算术平均 更新 λ（对线性 λ(t) 这恰等于严格的积分平均 λ̄ = λ₀ + b(t₁+t₂)/2），反复迭代至收敛（通常 3~6 次）。

重要说明：仅凭「厚度 + 导热系数 + 内侧温度」无法唯一确定外侧温度——还必须知道外侧向环境散热的能力（h₂ 与环境温度），否则只能得到 q·δ/λ 的温降关系式。本工具采用工程上最常用的「外侧对流+辐射换热」边界条件。

  • 假设：一维稳态、材料均质、λ 取各层平均温度对应值、忽略层间接触热阻与内表面结焦/积灰。圆筒壁按每米长度计算（不计端部散热）。
  • 外表面温度高于 60 °C 时存在烫伤风险；GB/T 3486 规定环境 25 °C 时工业锅炉外壁表面平均温度不得超过 50 °C；一般钢制炉壳建议控制在 80~100 °C 以内。
  • h₂ 在高温下辐射占比很大（表面 200 °C 时辐射约占 2/3），建议用「自动（对流+辐射）」或按表面温度查综合值，而不是固定取 10。
  • 圆筒壁与平壁差异：内径 2 m、衬厚 345 mm 时，平壁近似会把外表面温度高估约 7%；内径越大越接近平壁。

瞬态计算模型与说明

同步模式（瞬态导热）：把选项卡 ① 算出的稳态温度场作为 t = 0 的初始条件，用一维瞬态导热方程做有限体积离散，时间方向取 Crank-Nicolson 隐式格式（Thomas 追赶法）：

平面壁：ρc ∂T/∂t = ∂/∂x ( λ(T) ∂T/∂x )
圆筒壁：ρc ∂T/∂t = (1/r)·∂/∂r ( r·λ(T) ∂T/∂r )
界面导热系数按该面所跨各层材料的串联热阻求等效值
外表面： −λ ∂T/∂n = h₂(T_s)·(T − T∞)   （内侧绝热时 ∂T/∂n = 0）
时间步长几何递增：起始 Δt ≈ 0.5·ρc·ΔV/(2λ·A)，之后每步 ×1.06，最长 ≈ 总时长/50
Crank-Nicolson 无条件稳定；离散格式已用能量守恒校核（偏差 0.0000%）
  • 内侧边界：绝热 = 停炉后炉门关闭；恒温 = 内侧温度维持不变；换热 = 内表面按 h₁ 与内侧气体换热。
  • 曲线为各层界面温度：内表面、每个层间界面、外表面（炉壳）。
  • λ 按 λ(t) = λ₀ + b·t 逐点更新；忽略接触热阻、辐射的内部传递与材料相变。
  • 网格约 2.5 mm（厚 0.35 m 时约 140 节点）；隐式格式无稳定性限制，时长再长也不降精度。
  • 查询值由相邻输出点线性插值；曲线非单调时同一温度可能对应多个时间，会全部列出。
