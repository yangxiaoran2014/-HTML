# 耐火材料温度计算器

版本：1.0.2（2026-10-19）。计算逻辑保持原样，本次完善自动更新功能。

## GitHub Pages 部署

1. 在已登录的 GitHub 新建仓库，例如 refractory-calculator。使用免费账户部署时可选择公开仓库，网页源码会公开。
2. 将本目录中的 index.html、version.js、.nojekyll 上传到仓库根目录并提交（不要上传外面的文件夹或 ZIP 本身）。
3. 打开仓库 Settings → Pages，在 Build and deployment 中选择 Deploy from a branch。
4. 分支选择 main，文件夹选择 /(root)，点击 Save。
5. 等待 Pages 构建成功，在 Settings → Pages 中打开实际发布地址。

## 自动更新

上线后首次打开约 2.5 秒检查更新；页面可见时每 5 分钟检查；切回页面（距上次检查超过 1 分钟）或恢复网络时也会检查。每次请求都会带缓存参数，避免清单被旧缓存遮挡。有新版时提示刷新，不会自动打断正在进行的计算。刷新会重置当前输入，建议先保存计算结果。

手动点击页脚“检查更新”可重新提示此前忽略的版本。检查有 15 秒超时，并避免重复请求。

发布新版时，修改 index.html 末尾 VERSION / BUILD，并同步修改 version.js 的 version / build / notes。版本号采用三段数字，例如 1.0.2；一起提交两个文件。Pages 发布及缓存更新需要时间。

## 本地副本

直接双击 HTML 可计算。当前版本已经填入线上 `version.js` 地址，本地副本也会自动检查更新；发现新版本时点击「打开线上新版」即可使用最新页面。
